# ⚡ Manjit Video Downloader (Portable 4K Edition)

A high-performance, standalone Windows application built to download videos and audio from YouTube, Instagram, Facebook, TikTok, Reddit, and X (Twitter) up to 4K Ultra HD.

---

### 🚀 Key Features
- **All-in-One Universal Support:** Download from YouTube, Instagram (Reels & Posts), Facebook, TikTok, X, and more.
- **True 4K & Ultra HD:** Full resolution support including 4K (2160p), 1080p FHD, 720p HD, and 320kbps MP3 audio extraction.
- **Embedded FFmpeg Engine:** No external dependencies. Video and audio streams merge automatically inside a single executable.
- **Modern Dark UI:** Clean, responsive interface with real-time download speed meters, progress bars, and metadata previews.
- **Zero Installation Required:** Fully portable `.exe` file. Just run and download.

---

### 💻 System Requirements
- Windows 10 / 11 (64-bit)
- No Python or FFmpeg installation required

---

### 📥 How to Run
1. Go to **Releases** and download `Manjit Video Downloader.exe`.
2. Double-click to launch.
3. Paste any video link, pick your target quality, and click **Download**.

> *Note: If Windows SmartScreen shows a prompt on first launch, click **More info** -> **Run anyway**.*
>
